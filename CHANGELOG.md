# Changelog

## 2026-10-20: progress and completion

- Added timestamp-based progress for source measurement, encoding and final verification.
- Show stage percentage, elapsed time, estimated stage time remaining, file count and batch summary.
- Added a macOS completion notification and a separate dialog with Reveal in Finder.
- Allowed the Raycast launcher to find a processor beside it or in the repository's scripts folder.
- Documented late filename collisions and the distinction between numerical QC and sound approval.

Audio targets, encoding settings and normalization behavior are unchanged.
Potential mastering changes are documented as plans, not shipped functionality.

- Local podcast delivery exports, two-pass normalization and encoded-file QC.
- File/folder input, kebab-case output names, source preservation and optional reports.
- Raycast launcher and installable agent skill.
- Source metadata removed from exports; no recordings or private reports bundled.
